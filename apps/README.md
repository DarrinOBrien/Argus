# apps

Your projects go here. Start a new one from the reference loop:

```bash
skills/iq9-always-on-agent/scripts/scaffold.sh apps/my-agent
```

Choose your app's name in place of `my-agent`. The scaffold uses the reference GenieX/CPU d1 integrations. Each app needs a README that covers how to run it, what you measured (with the actual runtime version, model revision, and precision), and its offline status. See [`AGENTS.md`](../AGENTS.md).
